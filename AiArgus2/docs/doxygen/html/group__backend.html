Backend implementation of the ArgusAI system.

Backend implementation of the ArgusAI system.

The backend module provides the core functionality for object detection and segmentation, implemented as a FastAPI-based REST API server.

Components

Detection Module

The detection module handles object detection using YOLOv8 models:

  • Real-time object detection
  • Configurable detection parameters
  • Support for multiple object classes

Segmentation Module

The segmentation module provides instance segmentation capabilities:

  • Instance segmentation using YOLOv8-seg
  • Mask generation and visualization
  • Class-specific segmentation

API Endpoints

The API module exposes REST endpoints for:

  • Image upload and processing
  • Detection and segmentation requests
  • Configuration management
  • Status monitoring

Usage

The backend can be accessed through:

  1. REST API endpoints
  2. WebSocket connections for real-time updates
  3. Direct Python imports for integration

Configuration

The backend can be configured through:

  • Environment variables
  • Configuration files
  • API endpoints

Models

The system uses the following YOLO models:

  • yolov8n.pt: Lightweight detection model
  • yolov8n-seg.pt: Lightweight segmentation model
  • yolov8l.pt: Large detection model

Dependencies

Key dependencies include:

  • FastAPI
  • Ultralytics YOLO
  • OpenCV
  • NumPy
  • PyTorch
