Installation Guide

Prerequisites

Before installing ArgusAI, ensure you have the following prerequisites:

  • Python 3.8 or higher
  • Node.js 16 or higher
  • Git
  • CUDA-capable GPU (recommended)

Backend Installation

  1. Clone the repository:
    git clone https://github.com/yourusername/ArgusAI.git
    cd ArgusAI
  2. Create and activate a virtual environment:
    python -m venv venv
    source venv/bin/activate # On Windows: venv\Scripts\activate
  3. Install backend dependencies:
    cd backend
    pip install -r requirements.txt
  4. Download YOLO models:
    • yolov8n.pt
    • yolov8n-seg.pt
    • yolov8l.pt

Frontend Installation

  1. Navigate to the frontend directory:
    cd ../frontend
  2. Install frontend dependencies:
    npm install

Configuration

  1. Backend configuration:
    • Copy .env.example to .env
    • Update configuration values as needed
  2. Frontend configuration:
    • Copy .env.example to .env
    • Update API endpoints and other settings

Running the Application

  1. Start the backend server:
    cd backend
    uvicorn main:app --reload
  2. Start the frontend development server:
    cd frontend
    npm run dev
  3. Access the application:
    • Frontend: http://localhost:5173
    • Backend API: http://localhost:8000
    • API Documentation: http://localhost:8000/docs

Troubleshooting

Common issues and solutions:

  • CUDA errors: Ensure CUDA is properly installed and compatible with PyTorch
  • Port conflicts: Change ports in configuration files
  • Model loading errors: Verify model files are in the correct location
  • Dependencies issues: Update pip and npm to latest versions

Updating

To update the application:

  1. Pull latest changes:
    git pull origin main
  2. Update dependencies:
    # Backend
    cd backend
    pip install -r requirements.txt
    # Frontend
    cd ../frontend
    npm install
  3. Restart the application
