API Reference

Overview

The ArgusAI API provides RESTful endpoints for object detection and segmentation. All endpoints are prefixed with /api/.

Authentication

Currently, the API does not require authentication. All endpoints are publicly accessible.

Endpoints

GET /api/class-names

Returns the list of available object classes for detection.

Response:
{
"class_names": [
"person", "bicycle", "car", "motorcycle", "airplane",
// ... more classes ...
]
}

POST /api/detect

Performs object detection or segmentation on an uploaded image.

Request:
Content-Type: multipart/form-data
{
"file": <image_file>,
"task": "detection" | "segmentation",
"selected_classes": ["person", "car", ...],
"threshold": 0.25,
"show_labels": true,
"show_confidence": true,
"color": "#B9282B",
"thickness": 2
}
Response:
{
"image": "<base64_encoded_image>",
"format": "png",
"message": "Detection completed successfully"
}

Parameters

File

  • Type: File upload
  • Required: Yes
  • Description: Image file to process
  • Supported formats: JPG, PNG, JPEG

Task

  • Type: String
  • Required: Yes
  • Values: "detection" | "segmentation"
  • Description: Type of processing to perform

Selected Classes

  • Type: Array of strings
  • Required: No
  • Description: List of object classes to detect
  • Default: All classes

Threshold

  • Type: Float
  • Required: No
  • Range: 0.0 to 1.0
  • Default: 0.25
  • Description: Confidence threshold for detections

Show Labels

  • Type: Boolean
  • Required: No
  • Default: true
  • Description: Whether to show class labels on the output image

Show Confidence

  • Type: Boolean
  • Required: No
  • Default: true
  • Description: Whether to show confidence scores on the output image

Color

  • Type: String
  • Required: No
  • Default: "#B9282B"
  • Description: Color for bounding boxes and labels (HEX format)

Thickness

  • Type: Integer
  • Required: No
  • Default: 2
  • Description: Thickness of bounding boxes in pixels

Error Responses

All endpoints may return the following error responses:

{
"error": "Error message description"
}

Common error codes:

  • 400: Bad Request - Invalid parameters
  • 413: Payload Too Large - Image file too large
  • 415: Unsupported Media Type - Invalid file format
  • 500: Internal Server Error - Server-side processing error

Examples

cURL Example

curl -X POST "http://localhost:8000/api/detect" \
-H "Content-Type: multipart/form-data" \
-F "file=@image.jpg" \
-F "task=detection" \
-F "selected_classes=[\"person\",\"car\"]" \
-F "threshold=0.25" \
-F "show_labels=true" \
-F "show_confidence=true" \
-F "color=#B9282B" \
-F "thickness=2"

Python Example

import requests
url = "http://localhost:8000/api/detect"
files = {"file": open("image.jpg", "rb")}
data = {
"task": "detection",
"selected_classes": ["person", "car"],
"threshold": 0.25,
"show_labels": True,
"show_confidence": True,
"color": "#B9282B",
"thickness": 2
}
response = requests.post(url, files=files, data=data)
result = response.json()
