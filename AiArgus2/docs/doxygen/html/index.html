ArgusAI Documentation

Introduction

ArgusAI is an advanced AI-powered object detection and segmentation system that provides real-time analysis of images and video streams. The system leverages state-of-the-art YOLO (You Only Look Once) models to deliver high-performance object detection and instance segmentation capabilities.

Key Features

  • Real-time object detection using YOLOv8
  • Instance segmentation capabilities
  • Support for multiple object classes
  • Configurable detection parameters
  • RESTful API interface
  • Modern web-based user interface

Architecture

The system is built with a modern client-server architecture:

  • Backend: FastAPI-based REST API server
  • Frontend: React-based web interface

Core Modules

  • Object Detection: Core detection functionality
  • Instance Segmentation: Segmentation capabilities
  • API Interface: REST API endpoints
  • User Interface: Web-based UI components

Usage

The system can be used through:

  1. Web Interface: Access the user-friendly web interface at http://localhost:5173
  2. API: Make direct API calls to the backend endpoints
